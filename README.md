# user_registration_system · v0.3.1

## My second Front-End project built with React.

The concept is simple: a registration form where **everything goes wrong** in the most professional way possible.
The site simulates a backend team that clearly **never touched a frontend in their lives** — broken UX, questionable design decisions, and forms that fight back. But as you progress, you'll discover the backend isn't doing much better either.
What to expect:

## Features

- A multi-step registration with increasingly unhinged form fields
- Each level presents a basic question in a uniquely terrible way
- The answers are always obvious — if you're paying attention
- Deeply serious terminal aesthetics over deeply unserious content
